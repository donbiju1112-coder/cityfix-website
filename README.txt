CITYFIX WEBSITE — MVP
=======================

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge/Firefox.
3. No server is required for this demo.

Included:
- Responsive landing page
- Service cards
- Service search
- City selector
- Booking modal
- Booking data stored in browser localStorage
- Provider CTA
- Login placeholder
- Mobile responsive layout

Not yet connected:
- Real user authentication
- Real database/backend
- Provider matching
- Online payments
- SMS/WhatsApp notifications
- Admin dashboard

These should be added before using this as a real commercial service.
